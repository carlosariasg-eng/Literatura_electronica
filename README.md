# Literatura electrónica

Página de inicio con las piezas de literatura electrónica de Carlos Arias Galindo para el curso.

## Archivos que deben estar en esta carpeta

Cada pieza es un archivo HTML independiente, con el mismo nombre que aparece en `index.html`:

- diccionario-fisica-poetica.html
- laboratorio-babel-95.html
- babel-95.html
- taller-babel-95.html
- hexagono-de-babel.html
- cuaderno-de-babel.html
- laboratorio-maquinas-textuales.html
- gimnasia-del-poema.html
- mascaras-para-octavio.html
- palimpsesto-vivo.html
- revista-numero-cero.html

## Publicación

El sitio se publica con GitHub Pages desde la rama principal (Settings → Pages → Deploy from a branch → `main` / root).
